# 1.002 Course syllabus
Reading • 10 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/supplement/cQaYs/1-002-course-syllabus

This course, CM3015, is designed to provide a broad and deep understanding of Machine Learning and Neural Networks. It functions as an advanced module, building upon prior machine learning content. A primary focus of the module is exploring a comprehensive range of machine learning techniques. Specifically, the course includes an in-depth exploration of deep neural networks. CM3015 aims to provide students with a more powerful and advanced toolkit for data analysis. Throughout the course, students will learn how to solve several common machine learning problems. These applied problems include regression and classification tasks. The curriculum also covers clustering, which deals with grouping similar data points. Furthermore, students will learn techniques for matrix completion and pattern recognition. A critical element of the study involves understanding how neural networks can be trained and optimized. The material emphasizes the practical application of deep neural networks. Additionally, students will be taught how to utilize professional machine learning and neural network software libraries. These libraries enable the rapid development and implementation of advanced machine learning systems. A key component of the learning process involves verifying and accurately evaluating the results generated by these systems. Successful completion of this course grants students five specific competencies. First, they will be able to explain and compare fundamental machine learning concepts. They will also gain the ability to effectively use several distinct machine learning algorithms. Second, students will analyze the differences between various machine learning problems. This analysis covers types such as supervised/unsupervised, classification/regression, clustering/dimensionality reduction. Third, a crucial skill developed is the selection and justification of appropriate feature representations for different data types. Fourth, students will describe the basic components of a neural network structure. They will also learn how these components combine to form moderately complex learning architectures. Finally, students must select and apply standard machine learning methods directly onto data sets. The primary academic resource for this course is the textbook, *Deep Learning with Python*. This textbook is the first edition, authored by F. Chollet. It is published by Manning Publications in 2017.

Machine learning (ML) is employed because it allows learning from data rather than relying on hardcoded solutions. This approach is necessary in cases where the problem's underlying model is unknown. For instance, determining if a specific face is depicted in an image cannot be solved through static coding alone. ML algorithms enable us to learn this complex function by observing large datasets of relevant images and non-relevant images.

There are two main categories of machine learning problems: supervised learning and unsupervised learning. In supervised learning, every input sample, $x$, is associated with a known label, $y$. The goal here is to learn mappings from the inputs to specific outputs, denoted as $x \to y$. For example, if $x$ is an image, $y$ might be 1 if the image contains the target object, or 0 otherwise.

Unsupervised learning deals with datasets where samples $x$ are presented without any pre-assigned labels. In this scenario, the objective is typically to observe the data and cluster individual samples. Using the analogy of images containing xylophones and goats, if no labels are given, the goal might be to group them into distinct subgroups based on a measure of similarity.

A clear method to categorize an ML problem is to ask whether the labels $Y$ are provided for the training data. If labels are absent, we face an unsupervised learning problem, such as grouping images of goats and xylophones. Conversely, if labels are available, we employ a supervised learning setup, allowing the model to be trained on the known outcomes.

When utilizing supervised learning, the nature of the desired output determines the specific problem type. If the output is binary, such as deciding if an image is a goat or a xylophone (a 1 or 0 output), the problem is classified as a classification problem. A classification task falls under the broader definition of learning discrete outputs.

If, however, the output is a continuous number—for instance, predicting the price of a goat as it fluctuates in a market—the problem becomes a regression problem. Regression involves predicting a continuous numerical value, such as a financial price or cost.

Finally, there is a third category: reinforcement learning. This type focuses on predicting a sequence of actions that will lead to a specific, desired reward. Consider learning to play a video game: actions are taken, and the outcome (win or loss) provides feedback. This feedback is fed back into the algorithm, enabling the system to iteratively refine its actions and learn to perform better over time.

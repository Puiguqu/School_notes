## 02_2.602_Further_reading_Reading_1h

# 2.602 Further reading
Reading • 1h - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/supplement/NSXhT/2-602-further-reading

The course provides foundational material, but students desiring a deeper exploration into Machine Learning (ML) applications are directed toward extensive online resources.

For practical implementation knowledge, specific Python documentation is provided concerning two major algorithms. Materials detailing the k-nearest neighbour implementation can be found on the scikit-learn nearest neighbour module documentation. This documentation is accessible at: `http://scikit-learn.org/stable/modules/neighbors.html`. A separate tutorial for decision trees in Python is provided via the scikit-learn documentation. This resource is located at: `https://scikit-learn.org/stable/modules/tree.html`.

Additionally, the course textbook by Chollet briefly discusses decision tree classifiers in Additional Chapter 1, section 1.2. For a comprehensive academic overview of supervised classification, students are directed to Ethem Alpaydin’s book. The full citation for Alpaydin’s text is: E. Alpaydin, *Introduction to machine learning*. (Cambridge, MA: MIT Press, 2014) 3rd edition [ISBN 9780262028189].

Alpaydin’s book covers the general principles of supervised classification in Sections 2.1 and 2.5. Furthermore, Alpaydin offers an in-depth examination of decision trees specifically in Chapter 9, spanning sections 9.1 to 9.3.

# 3.101 Introduction to linear regression
Video • 1 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/TGwX2/3-101-introduction-to-linear-regression

This analysis introduces linear regression, a powerful technique within the field of supervised learning. Regression models are designed to predict continuous values based on input data. Linear regression serves as a foundational technique for fitting this data using simple linear equations. Conceptually, this involves visualizing a line that optimally represents the relationship between data labels and their inputs in a possibly high-dimensional space. Optimizing a linear regression model requires a first-order optimization method known as gradient descent. Gradient descent is the commonly employed algorithm used to determine the best linear model parameters for a given dataset. Furthermore, discussions will cover crucial technical aspects for advanced applications. Specifically, the text notes the necessity of scaling features before applying multivariate linear regression. The learning process also includes methods for automatically detecting convergence in iterative algorithms.

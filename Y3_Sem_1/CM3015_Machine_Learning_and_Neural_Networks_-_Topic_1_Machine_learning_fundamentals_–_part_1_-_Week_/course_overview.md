### 05_1.102_Types_of_ML_Video_3_min

# 1.102 Types of ML
Video • 3 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/9eWWs/1-102-types-of-ml

Machine learning (ML) is employed because it allows learning from data rather than relying on hardcoded solutions. This approach is necessary in cases where the problem's underlying model is unknown. For instance, determining if a specific face is depicted in an image cannot be solved through static coding alone. ML algorithms enable us to learn this complex function by observing large datasets of relevant images and non-relevant images.

There are two main categories of machine learning problems: supervised learning and unsupervised learning. In supervised learning, every input sample, $x$, is associated with a known label, $y$. The goal here is to learn mappings from the inputs to specific outputs, denoted as $x \to y$. For example, if $x$ is an image, $y$ might be 1 if the image contains the target object, or 0 otherwise.

Unsupervised learning deals with datasets where samples $x$ are presented without any pre-assigned labels. In this scenario, the objective is typically to observe the data and cluster individual samples. Using the analogy of images containing xylophones and goats, if no labels are given, the goal might be to group them into distinct subgroups based on a measure of similarity.

A clear method to categorize an ML problem is to ask whether the labels $Y$ are provided for the training data. If labels are absent, we face an unsupervised learning problem, such as grouping images of goats and xylophones. Conversely, if labels are available, we employ a supervised learning setup, allowing the model to be trained on the known outcomes.

When utilizing supervised learning, the nature of the desired output determines the specific problem type. If the output is binary, such as deciding if an image is a goat or a xylophone (a 1 or 0 output), the problem is classified as a classification problem. A classification task falls under the broader definition of learning discrete outputs.

If, however, the output is a continuous number—for instance, predicting the price of a goat as it fluctuates in a market—the problem becomes a regression problem. Regression involves predicting a continuous numerical value, such as a financial price or cost.

Finally, there is a third category: reinforcement learning. This type focuses on predicting a sequence of actions that will lead to a specific, desired reward. Consider learning to play a video game: actions are taken, and the outcome (win or loss) provides feedback. This feedback is fed back into the algorithm, enabling the system to iteratively refine its actions and learn to perform better over time.

The course structure reflects this breadth, with topics progressing from introductory fundamentals to specialized areas. Week 1 introduces fundamental concepts, including the distinction between supervised and unsupervised learning (Sections 1.101, 1.102). The specialized topics are covered through subsequent weeks. Classification is covered in Weeks 3 and 4, while Regression forms the focus of Weeks 5 and 6. Unsupervised learning is extensively explored in Weeks 9 and 10. Neural networks and deep learning are detailed in Weeks 11 through 18, building upon the mathematical foundation in Weeks 12, 13, and 14. The overall structure demonstrates a comprehensive approach to machine learning, moving from foundational principles to advanced network architectures.

### 02_6.302_PCA_Video_10_min

# 6.302 PCA
Video • 10 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/BEee6/6-302-pca

Principal Component Analysis (PCA) fundamentally relies on understanding variance within the dataset. When dealing with $N$ samples and $F$ features, the data is represented as a matrix $X$. Calculating the sample mean involves summing over all samples and dividing by the total number of samples. To assess feature relationships in this multidimensional space, we utilize the covariance algorithm. Covariance measures how the data samples move together and how variables change relative to the mean. The core premise of PCA is to linearly transform data from one dimension to another. This transformation is achieved by multiplying the original data $X$ by a PCA transformation matrix, $W$, resulting in output data $Y$ in the new space.

For instance, a 3D to 2D mapping uses a $3 \times 2$ matrix $W$ applied to a $3 \times 1$ feature vector. The critical challenge is determining the values of $W$. The primary objective function is to maximize the covariance of the output data $Y$. Mathematically, this covariance is represented as $W^T \text{Cov}(X) W$. By setting $S = \text{Cov}(X)$, the optimization goal is to find $W$ that maximizes $W^T S W$.

To prevent $W$ from tending toward infinity, a crucial constraint is added: $W^T W = I$, where $I$ is the identity matrix. This constraint ensures that the projected features remain linearly independent and orthogonal. The optimal matrix $W$ is found using Eigenanalysis. This process involves taking the covariance matrix $S$ and performing Eigenanalysis on it. This yields two outputs: a vector of Eigenvalues and a matrix of corresponding Eigenvectors.

These outputs are linked such that multiplying the Eigenvectors $W$ by the covariance matrix $S$ equals multiplying the Eigenvectors by the corresponding scalar Eigenvalues. The PCA procedure begins by centering all data by subtracting the mean from the feature vectors $X$. Next, the covariance matrix $S$ is calculated over the centered data. Eigenvalues and Eigenvectors are then computed using Eigenanalysis.

The fourth step involves reordering the resulting Eigenvalues from largest to smallest. The largest eigenvalues correspond to the Eigenvectors that capture the most variance, which are the principal components. For dimensionality reduction to $k$ dimensions, we select the top $k$ eigenvectors, forming the matrix $W_k$. The final projection is achieved by calculating the output data $Y$ as $Y = W_k^T X$.

A powerful feature of PCA is that the transformation can be reversible if all principal components are retained. We can take $W_k$ and multiply it by the projected data $Y_k$ to map it back into the original dimensional space. This reversal allows for faithful data reconstruction. However, when dropping eigenvectors (i.e., reducing dimensions), the compression is inherently lossy. In a demonstration, three features ($f_1, f_2 = -f_1, f_3 = 2f_1$) were shown to be linearly dependent. These three features could be completely represented by a single dimension, demonstrating that the minimum number of dimensions required is often far less than the features provided.

### 03_7.101_Artificial_intelligence_(AI),_machine_learning_(ML)_and_deep_learning_(DL_Video_2_min

# 7.101 Artificial intelligence (AI), machine learning (ML) and deep learning (DL
Video • 2 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/SKzNo/7-101-artificial-intelligence-ai-machine-learning-ml-and-deep-learning-dl

Artificial intelligence (AI) is fundamentally defined as mechanical thought, enabling machines to execute tasks previously considered solely human capabilities. Early in its development, AI focused on modeling thought through the manipulation of symbols, such as rearranging mathematical equations. This symbolic approach demonstrated logical calculus, exemplified by the syllogism: "If it is raining, I will get wet; it is raining, therefore, I will get wet." However, this traditional logic-based system failed miserably when confronted with tasks possessing undefinable or amorphous rules.

The conventional computational approach involves encoding specific rules, including logic and heuristics (rules of thumb), directly into a program. The program is then presented with data, and the computer processes the defined rules to announce a result. A major paradigm shift occurred in the 1990s with the advent of machine learning (ML). In the ML paradigm, rules are not hard-coded; instead, they are dynamically learned.

The ML process trains by comparing input data against a desired output response. This creates a parameterized map between the input and the target, allowing the machine to derive implicit rules internally. This fundamental change made complex tasks, such as discerning dogs from cats in images—which was impossible through hard coding—now feasible.

Deep learning (DL) represents a more recent and supercharged advancement building upon machine learning. DL is implemented specifically through the use of neural networks. Both ML and DL rely heavily on vast and enormous datasets to function effectively. Crucially, these methods currently lack a firm mathematical base and emphasize a hands-on, practical approach. The ultimate objective of ML and DL remains the search for meaningful transformations of raw data.

### 05_7.105_The_'deep'_in_deep_learning_Video_4_min

# 7.105 The 'deep' in deep learning
Video • 4 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/LJ5mV/7-105-the-deep-in-deep-learning

Deep learning models operate by applying successive transformations to input data. Initially, 2D red/black vectors are subjected to a sequence of transformations. This sequence includes a linear transformation, followed by a rotation, and finally a nonlinear projection. Each of these specific transformations is performed by a dedicated computational layer. A model is defined as "deep" if it incorporates three or more successive computational layers. Deep learning models fundamentally achieve their function through these multiple transformations.

These statistically deep models are almost invariably implemented as neural networks. Neural networks (or Artificial Neural Networks) were initially conceived as crude analogies to biological neural networks found in the brain. However, it is critical to note that current neural networks do not emulate brain function; they neither think nor learn in the same way that biological brains do. Functionally, we regard these networks more prosaically as a stack sequence of layered computational processes.

To illustrate this, consider training a network to recognize handwritten digits. The input starts as a small 28 by 28 pixel image, each representing a digit. This image must first be vectorized by placing every pixel value into a 1D array, which results in 784 elements. The darker a pixel, the larger its corresponding value in the vector. This vectorized sample is presented to the network's first layer.

Within the network, data is transformed as it flows forward from one layer to the next. The first layer transforms the original 784-element input into a 512-element vector. This resulting representation is often smaller than the original input vector, unless the data is exceptionally sparse. The 512-element vector then feeds into a second transformation layer. This second layer ultimately generates a 10-element vector of floating-point values. These output values represent the classification of the input, where each element corresponds to a specific digit (zero through nine). The magnitude of these values quantifies the network's confidence in its prediction; for instance, a high value in the eighth slot suggests a confident prediction of the digit '7'.

This entire process constitutes the operation of a neural network, and the training component is what allows it to learn. The course structure provides comprehensive coverage of these concepts. Key topics include Machine Learning fundamentals, Classification, Regression, and Model Evaluation (Week 1-9). Specifically, Topic 7 focuses on Neural Networks and Deep Learning. This module includes defining AI, ML, and DL, and detailing the concept of "The 'deep' in deep learning" (7.105). Further deep dives are promised in subsequent weeks, specifically covering the mathematical building blocks of neural networks.

# 8.312 Geometric interpretation of tensor operations
Video • 3 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/rQXHU/8-312-geometric-interpretation-of-tensor-operations

The text provides an advanced conceptual overview of neural network layers, focusing on the geometric and mathematical underpinnings of transformations. The foundation begins with the understanding that tensor elements can be interpreted as coordinates defining a high-dimensional geometric object. A single neural network layer implements a transformation defined by the function $f(W\cdot x + b)$.

The initial component, $W\cdot x$, represents a linear transformation of the input data. Mathematically, a function is linear if $f(x+y) = f(x) + f(y)$ and if $f(a \cdot x) = a \cdot f(x)$ for any scalar $a$ and vectors $x$ and $y$. Rotations, for instance, constitute a classic example of a linear function.

This linearity has significant geometric implications; sequential rotations (e.g., a $60^\circ$ rotation followed by a $30^\circ$ rotation) are equivalent to a single rotation by the sum of the angles ($90^\circ$).

However, when the bias term $b$ is introduced, the transformation $W\cdot x + b$ ceases to be linear, unless $b$ is zero. Instead, $W\cdot x + b$ is defined as an affine transformation, which is fundamentally a linear transformation followed by a translation.

Geometrically, this means the input object (like a rotated square example) undergoes both rotation and translation (e.g., translated by one unit right and one-tenth unit down).

The critical concept distinguishing a standard neural network layer is the subsequent application of a non-linear function $f$ to the affine transformation $W\cdot x + b$. Applying this non-linear function introduces distortions to the object.

The Rectified Linear Unit (ReLU) function serves as an example of this non-linear activation applied both before and after the transformations.

In summation, every layer in a neural network executes a non-linear data transformation described by $f(W\cdot x + b)$. This process leverages the combination of affine transformation and non-linear activation.

Collectively, a neural network, operating as a series of chained activations and affine transformations, implements a complex transformation on the input data, which exists as a high-dimensional geometric object. This overarching network function is composed of many simpler, sequential non-linear transformations. The network's capability is to unfold complex data structures—such as a paper sheet crumpled into a 1,000-dimensional ball—into something simple and meaningful.

### 05_8.408_Stochastic_gradient_descent_Video_4_min

# 8.408 Stochastic gradient descent
Video • 4 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/2OJMN/8-408-stochastic-gradient-descent

Optimizing neural networks requires minimizing a loss function, where the loss is at a minimum when its gradient with respect to weights ($w$) and biases ($b$) is zero. Calculating this gradient using standard methods is computationally prohibitive, especially given the likelihood of multiple solutions. To address this, an iterative scheme is employed that approximates the solution through small, stepwise movements. The fundamental principle involves scaling the gradient in the $w$ and $b$ directions by a small parameter called the learning rate ($\eta$). This scaled gradient is then subtracted from the current parameter values, effectively moving "down the hill" towards a minimum.

The true loss function is the combined loss over the entire training set (the batch), but even Batch Gradient Descent (BGD) is prohibitively expensive. Consequently, Stochastic Gradient Descent (SGD) is used, where the loss and gradient are calculated using small, randomly selected subsets of the training set, approximating the total loss via mini-batch loss. A simple one-dimensional loss function illustrates that multiple points, including local and global minima, can have a zero gradient.

SGD can be conceptualized as rolling a ball down a landscape, where the parameters ($w$ and $b$) are coordinates defining the ball's position. If the step sizes are too small, the ball may get trapped in a local minimum; conversely, if the step size is too large, it may never converge to a minimum. There is no way to know the optimal step size a priori because the loss landscape is unknown. TensorFlow offers several built-in optimizers, including SGD, Adagrad, and RMSprop, all implementing forms of SGD.

Many optimizers utilize momentum to actively attempt to avoid being stuck in local optimums. Momentum draws an analogy to the motion of a ball on a slope, governed by differential update rules. In this physics analogy, the total acceleration ($a$) combines the negative gradient (downward force) and an opposing friction force proportional to velocity.

The resulting algebraic update rule for velocity ($v$) is defined as: $v_{t} = \alpha v_{t-1} + \eta \cdot (-\text{Gradient})$. The parameters ($w$ and $b$) are then updated based on this velocity, treating $\Delta w$ and $\Delta b$ as the velocity components. This scheme is called momentum because the $\alpha \Delta w$ term reinforces motion in the direction of the previous change, similar to inertia.

The Momentum SGD algorithm uses $\alpha$ (the coefficient of friction, $0 \le \alpha \le 1$) and the learning rate ($\eta$) to control the parameter updates. The core idea of momentum is that it provides enough inertia to carry the parameters ($w$ and $b$) over the barrier between local and global optimums.

### 03_9.104_Layers_Video_5_min

# 9.104 Layers
Video • 5 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/pCZpv/9-104-layers

The foundational building block of a neural network is the layer, which functions by mapping tensors to tensors. These layers are parameterized by specific weights and biases and update their parameters via the Stochastic Gradient Descent (SGD) feedback loop. A typical neural network processing involves feeding a sample, transforming the data through successive layers, and ultimately producing an output.

In a dense or fully connected layer, the transformation involves an $n \times m$ weight matrix, where the incoming vector has length $m$ and the resulting transformed vector has length $n$. An associated bias tensor is an $n$-component vector that contributes to the layer's transformation.

A Recurrent Neural Network (RNN) features internal loops, enabling it to process ordered data by iterating through sequential elements. RNN layers are optimally suited for samples that possess a time ordering, such as weather measurements. Conversely, Convolutional Layers (ConvNets) are the preferred method for computer vision applications, using a small window to move across a 2D image and map the response to layer weights.

The function of different network types dictates their optimal use: dense networks process vector data, recurrent networks handle sequence data, and convolutional layers are recommended for computer vision tasks. Returning to dense layers, the fundamental operation is an affine transformation followed by the application of an element-wise function.

An affine transformation is defined as $w \cdot x + b$, which constitutes a 2D matrix transformation—such as rotation, reflection, or shear—followed by a translation. While affine transformations preserve straight lines and parallel lines, they are insufficient alone for data uncrumpling. This necessitates the inclusion of a non-linear element-wise activation function.

Common activation functions include Sigmoid, Rectified Linear Unit (ReLU), and Tanh. The Sigmoid function, for instance, acts as a smoothed-out, differentiable step function, mapping large positive inputs to 1 and large negative inputs to 0, with a smooth transition near zero.

In implementation, the input and output tensor shapes of a TensorFlow Keras layer are fixed upon creation. For example, a layer might receive an input shape with axis 1 having dimensions $7, 8, 4$, with the batch dimension (axis 0) remaining unspecified. The layer may then output a vector of length 32.

A downstream layer must be configured to accept this specific input vector length; if the subsequent layer requires 16 elements, it is specified using `layers.dense(16)`. Technically, the layer's weight tensor has a shape of $m \times n$, which is the reverse of the conventional matrix size $n \times m$.

The organizational structure of TensorFlow utilizes matrix transposes for tensor operations, though computationally, all quantities are arrays, and operations are executed as loops with defined counters and end conditions. This ensures that even complex matrix-vector multiplications function seamlessly within the framework. These concepts form the core mathematical and architectural blocks necessary for deep learning.

The core challenge addressed is that the initial training set is small. If this set is divided into a training and validation split, the resulting validation set becomes exceptionally tiny. Validation scores derived from such a small subset are highly sensitive to the specific constitution of that set.

K-fold cross-validation serves as the common solution to mitigate this sensitivity. In this technique, the entire dataset is systematically split into K distinct partitions. Typically, K is set to four or five partitions for the dataset. Consequently, K identical models are instantiated for training.

The methodology dictates that for any given fold, the network is trained on all data except that fold's partition. For example, in fold one, the model is trained on partitions two, three, four, up to K. Subsequently, the model is validated specifically on partition one.

A fresh network must be instantiated for each fold to ensure impartiality. For fold two, the training set includes partitions one, three, four, up to K, while the validation occurs on partition two. This robust process significantly reduces the dependence of the validation score on any single small set.

The specific implementation involves a K-fold training code where K is defined as four. Both training and validation processes are managed within a continuous loop. At each pass, a new network is instantiated, and a partial training set is sliced from the full training data.

The primary metric monitored is the validation mean absolute error (MAE). It is crucial to note that the MAE is recorded only at the termination of the training run, not after each individual epoch. Therefore, no history object is maintained for epoch-level tracking.

The training run observed utilized 100 epochs. The resulting MAE scores across the folds varied between 2.07 and 2.5. The derived average MAE was deemed significant because the target price range for the house prices spans from $10,000 to $50,000.

The transcript provides a detailed procedural breakdown of standard K-fold validation. This method involves splitting the entire training data into $K$ equal partitions. The validation process is performed by iterating over each fold. In each iteration, one partition serves as the validation data, while the remaining $K-1$ partitions are used for training.

This cycle continues, ensuring that every data point is used for validation exactly once across the $K$ folds. The core function of K-fold validation is to evaluate a fresh model trained and tuned on the combined partitions and subsequently validated on a held-out partition. This process allows for a robust estimation of the model's generalization capability.

A crucial subsequent step is retraining a fresh model on the entire training dataset after the $K$-fold evaluations are complete. This final model is then evaluated on a completely unseen test set to provide a final, unbiased measure of performance.

An advanced variant, known as iterated or repeated K-fold validation, introduces another layer of robustness. In this setup, the entire K-fold validation process is repeated $P$ times. In each repetition, a new set of $K$ models is trained and evaluated. The overall K-fold averages are then gathered and re-averaged across the $P$ repetitions. This iterated average provides a highly stable and refined mean of the K-fold scores. Although highly accurate, the iterated K-fold method is noted as being computationally expensive. # 10.405 Adding weight regularisation
Video • 4 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/KKcRb/10-405-adding-weight-regularisation

The discussion initiates with a fundamental choice regarding model selection, comparing a simple linear model ($y=x$) against a complex, tenth-order polynomial model. According to the principle of Occam's razor, simpler models are often preferred, even if a complex model fits the training data perfectly. However, perfect fitting can be detrimental, as a highly complex model will likely fail to generalize to new, unseen data. This lack of generalization occurs because the fit becomes too specific to the training noise, a phenomenon known as overfitting.

In the context of network design, simplicity translates to low capacity, which is analogous to limiting the number of parameters or weights. Large weight parameters are problematic because they significantly amplify input noise, causing the network to attempt to fit the noise rather than the underlying signal. Therefore, a model utilizing smaller weights is inherently more robust.

Weight regularization is a crucial technique used to prevent network weights from becoming too large and dominant. This technique applies a penalty to the loss function based on the magnitude of the weight parameters. There are two primary forms of regularization: L1 and L2.

In L1 regularization, a cost proportional to the absolute value of the weight parameters is added to the original loss function. Conversely, L2 regularization, also known as weight decay, adds a cost defined by the square of the weight parameters.

The implementation of regularization in frameworks like TensorFlow Keras is achieved by adding a weight to the `regularizer` instance within the model's argument list. Specifically, L2 regularization dictates that the term $0.001 \cdot W^T W$ is added to the loss function, where $W$ represents the weight matrix.

A comparison was demonstrated between an unregularized IMDb network and its L2-regularized counterpart, both having the same capacity of approximately 160,000 tuneable parameters. The findings clearly showed that the L2-regularized model was far more resistant to overfitting compared to the unregularized model. ### 03_2.301_Decision_tree_Video_7_min

# 2.301 Decision tree
Video • 7 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/AoY5x/2-301-decision-tree

Decision trees constitute a versatile class of machine learning algorithms capable of handling both classification and regression tasks. These models are highly effective for managing complex, non-linear datasets. Specifically, decision trees frequently serve as the foundational classifier within Random Forests, a powerful algorithm class. The structure of a decision tree begins at a root node, which poses a binary question based on the most information-rich feature. In the provided example distinguishing rabbits from hares, the root node uses the burrowing feature, as hares almost never burrow while all rabbits do. If the animal does not burrow, it is classified as a hare. If the animal can be found in a burrow, the process continues to a secondary split using a less distinguishing feature, such as ear length. The final class designations, reached through the traversal, are termed leaf nodes. When new data is presented, it is classified by descending the tree until an appropriate leaf node is reached. A crucial characteristic is that decision trees are "White Box" models, making them highly interpretable. This transparency derives from their foundation in a hierarchy of simple, easily visualized classification rules. This contrasts sharply with "black box" models, such as deep neural networks, where decision-making processes are opaque. Mapping the tree onto the feature space creates a decision boundary, which can be complex and non-linear. The CART algorithm, or Classification and Regression Decision Tree, is a common type; it is a binary tree where each non-leaf node spawns two children. The goal of training a CART is to fit a decision boundary that optimally separates distinct data groups. The algorithm starts at the root node by searching for a single feature and a threshold value that best splits the entire dataset. This optimal split selection is achieved by minimizing the impurity within each resulting decision region. Impurity is a measure of class mixture; aiming for zero impurity means a perfect separation can define a leaf node. If a region remains impure, the tree recursively grows to a second-level split on that subset of the data. This process continues until the dataset is perfectly partitioned into leaf nodes. A significant advantage is the tree's capacity to capture complex data relationships via intricate decision boundaries. However, a major danger is that decision trees are prone to overfitting, meaning they fit training data too perfectly and fail to generalize. This follows the principle of Occam's Razor, favoring simpler, more robust solutions. Practical solutions include regularization, which restricts the tree depth even if misclassifications occur. Alternatively, the preferred approach is to fully grow the tree and then perform pruning to find an optimal compromise. Determining the optimal split and feature combination is an NP-complete problem, rendering it computationally intractable for even small datasets. The CART algorithm mitigates this challenge by employing greedy training, evaluating only the optimal split sequentially at each node. Despite this lack of global optimization, greedy training often yields a robust overall solution. Furthermore, a key strength is that decision trees operate effectively on raw feature data. They do not require the time-consuming pre-processing steps, such as scaling or centering, necessary for algorithms like K-nearest neighbor. These algorithms remain incredibly powerful and flexible, extending from classification to regression tasks.

### 01_3.301_Gradient_descent_in_1D_Video_9_min

# 3.301 Gradient descent in 1D
Video • 9 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/26Vwa/3-301-gradient-descent-in-1d

The text introduces Gradient Descent, a core method for fitting data by minimizing error, following discussions on simple line fitting. A starting example uses three data points, where the error is measured using the Least Square Error, or the L2 loss. This L2 loss measures the distance between the actual label ($y$) and the hypothesis output ($\hat{y}$), calculated by squaring the difference and summing it across all data points. The loss function is plotted as a curve against varying parameters, such as $\Theta_1$. If the parameter values are chosen correctly, the loss reaches zero, indicating a perfect fit at a minimum point.

When sweeping across all possible parameter values, the resulting loss function forms a bowl-shaped curve, which is defined as convex. Convexity is crucial because it guarantees the existence of a single global minimum, which is the optimal point for fitting the line. This feature allows the use of the iterative technique known as Gradient Descent. The primary goal of Gradient Descent is to find the optimal parameter values that minimize this loss function.

The technique works by starting at a random point on the loss curve and iteratively moving "downhill." To move downhill, one must ascertain the gradient of the loss curve at the current point. This means calculating the slope and moving in the opposite direction of the steepest ascent. The basic principle requires the ability to differentiate the loss function.

The loss function involves the linear equation, $\Theta_0 + \Theta_1 \cdot x$, subtracted from the label $y$, squared, and summed over data points, often divided by 2 to simplify gradient calculation. Since there are multiple parameters ($\Theta_0$ and $\Theta_1$), partial derivatives must be computed. Focusing on $\Theta_1$, the partial derivative is a straightforward function derived from the loss.

To implement Gradient Descent, the core process involves taking the current parameter value and subtracting a term dependent on the calculated gradient. This term incorporates the learning rate, $\alpha$, which controls the speed of the algorithm. The Gradient Descent update rule is: $\text{Parameter} \leftarrow \text{Parameter} - \alpha \cdot \text{Derivative}$.

If the current slope is steep and positive, subtracting a large quantity moves the parameter far away from that steep ascent. As the algorithm approaches the convergence point (the bottom of the bowl), the slope decreases, leading to smaller, more incremental steps. Convergence is reached when the change between consecutive steps or steps in loss becomes negligible.

Gradient Descent fundamentally requires the loss function to be differentiable and convex. In summary, the algorithm operates by: finding a point, calculating the loss, determining the gradient (derivative) at that point, and applying the update rule. This iterative process continues until a minimum point (convergence) is found. Setting the learning rate $\alpha$ is critical: if $\alpha$ is too small, convergence is painfully slow; if $\alpha$ is too large, the algorithm may never converge, instead oscillating around the minimum.

### 03_3.305_Data_scaling_Video_3_min

# 3.305 Data scaling
Video • 3 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/Sirol/3-305-data-scaling

When handling multivariate data, significant issues arise, particularly when implementing gradient descent. The magnitude discrepancy between features is often vast; for instance, error counts might be in the tens or hundreds, while home kilowatt-hours can exceed 10,000. This massive difference in value scaling causes problems during the learning of a linear model. Specifically, the resulting $\Theta$ values become unbalanced, leading to some coefficients being very large and others being very small. To mitigate these instabilities, a crucial practical step in machine learning is to scale the data beforehand.

A common method employed for scaling is min-max normalization. This technique forces all raw data points to fall within the range of zero and one, inclusive. The formula for min-max normalization involves taking a single data point, subtracting the minimum value of that feature, and then dividing by the range (maximum value minus minimum value). This ensures that all features fit neatly between 0 and 1, as illustrated in the provided example table.

Scaling is often essential for the successful operation of gradient descent. When exploring parameters $\Theta_1$ and $\Theta_2$, an unscaled dataset can produce an elongated loss curve. In this scenario, one parameter ($\Theta_2$) may be stretched into the hundreds of thousands, while another ($\Theta_1$) remains small. Attempting gradient descent on such unscaled data requires an excessively large number of steps to converge, thereby creating significant problems with the optimization process.

By scaling the data to comparable and equivalent values, the convergence speed of gradient descent is drastically accelerated. While min-max normalization is one technique, there are several other popular scaling methods.

Another widely used approach is range normalization centered on the mean. Unlike min-max normalization, which bounds data between zero and one, this method centers the data around its mean. This technique performs particularly well when the dataset tends to be normally distributed.

A third approach is standardization, which is also known as the Z-score method. Standardization centers the data on the mean, but instead of bounding it between zero and one, it divides all data points by the standard deviation of the dataset. Each of these scaling methods (min-max, range, standardization) possesses different advantages and disadvantages. Determining the best approach requires examining the specific characteristics of the data through literature review. The associated module covering this topic is 3.305 Data scaling.

### 01_4.101_Overfitting_and_underfitting_Video_4_min

# 4.101 Overfitting and underfitting
Video • 4 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/eHS12/4-101-overfitting-and-underfitting

The analysis of model fitting begins by examining the limitations of overly simple models, such as those derived from linear regression. If a model fails to adequately represent the data, it is described as underfitting. This state occurs because the model is overly simple and inflexible, leading to a technical term known as high bias.

Conversely, increasing model complexity, such as fitting data with a fourth-degree polynomial, can lead to overfitting. In an overfit scenario, the line fits the training data perfectly, but its excessive complexity results in high variance. The core goal in machine learning is to develop a model that is highly generalizable, meaning it fits the training data well while performing reliably on new, unseen data.

A guiding philosophical premise for model creation is Ockham’s Razor, which advises using the simplest possible solution that is sufficient to solve the problem. To quantitatively evaluate generalizability, the bias-variance curve is utilized. This curve plots error against a measure of model complexity, such as the degree of a polynomial.

When training on a dataset, the initial error typically decreases as the model complexity increases. However, the error measured on an independent test set follows a different trajectory. At low complexity, the model underfits (high bias); at high complexity, it overfits (high variance). The ideal model exists at a "sweet spot" where the test error is minimized.

To ensure a model is generalizable and avoids this dichotomy, two primary approaches are employed. The first approach is reducing the number of features, often through manual, heuristic feature selection. While effective, this process can be tedious, particularly with complex data.

Alternatively, automation can be used for model or feature selection, often utilizing cross-validation techniques. The second critical strategy is regularization. This method retains all initial features but systematically reduces the magnitude of the parameter values. Regularization effectively diminishes the influence of specific features, making the model less susceptible to noise and improving generalizability.

### 03_4.301_Cross-validation_Video_5_min

# 4.301 Cross-validation
Video • 5 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/QyHda/4-301-cross-validation

The primary goal in machine learning is to avoid overfitting, which occurs when the training data is used identically for testing, leading to models that perform poorly on unseen, real-world data. A fundamental technique to mitigate this is the train-test split, where a small portion of the data (e.g., 10%) is set aside exclusively for testing. The remaining data is then used to train the algorithm, and the held-out test data acts as a proxy for real-world, previously unseen data. Due to limited dataset size, this basic approach can be inefficient, leading to the need for a more comprehensive method: N-fold cross-validation.

N-fold cross-validation maximizes data utilization by splitting the entire dataset into $N$ equal sections, or folds. In this procedure, the algorithm trains on $N-1$ folds while testing on the remaining single fold. This process is repeated $N$ times, cycling through each fold as the reserved test set. The final performance metric (accuracy or error) for the algorithm is then determined by calculating the average across all $N$ iteration results. This technique allows every data point to participate both in training and testing, preventing the reliance on a single, potentially biased split.

However, machine learning algorithms often possess multiple hyperparameters (e.g., $k$ in K-nearest neighbors or distance measures like Euclidean or Manhattan) that need optimization. Evaluating these parameters using only the training set results in overfitting, as the hyperparameter selection process is tied to the data being trained on. Similarly, using the final dedicated test set for parameter tuning is improper because it pollutes the test set with information, compromising its integrity.

The definitive solution for simultaneously tuning hyperparameters and evaluating performance without compromising data integrity is N-fold nested cross-validation. This robust method involves an outer loop (the main fold) and an inner loop (the hyperparameter evaluation). First, the entire dataset is split into a final train set and a test set. Within the train set, the nested structure begins.

In the inner loop, the training data is further subdivided into a smaller training subset and a validation set. It is within this validation set that various possible hyperparameters are evaluated. For example, all potential $k$ values and distance measures are trained and tested against the small validation set to find the optimal configuration. Once the best hyperparameters are identified through the inner loop, they are applied to the larger training set of the outer loop. Finally, this optimally tuned algorithm is evaluated on the original, untouchable test set of that fold. This entire process is repeated for all folds, providing an average error that reflects the model's true generalization capability.

# 6.101 Introduction to unsupervised Learning
Video • 2 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/z95eG/6-101-introduction-to-unsupervised-learning

Supervised learning is introduced as the most straightforward and dominant set of approaches for applying machine learning algorithms. This methodology fundamentally requires the existence of labels to dictate the production or output of an algorithm. These essential labels are typically provided by human experts, such as radiologists annotating X-rays for specific disease types. This reliance on expert judgment, however, presents significant challenges. Firstly, the process of human annotation is inherently costly. Secondly, it is prone to errors because it depends entirely on individual human judgment. The problem is exacerbated when multiple experts assess the same sample, leading to expected deviations among their ratings.

This inherent limitation in labeling introduces the necessity of unsupervised learning. Unsupervised learning allows for thorough data analysis and interpretation without relying on predefined labels. The discourse focuses on two fundamental categories within unsupervised machine learning: clustering and dimensionality reduction. Clustering is defined as an unsupervised method utilized to arrange data into interpretable subgroups. Its primary utility is serving as a powerful tool for data analysis and interpretation itself. Furthermore, clustering can be used to enhance supervised machine learning efficiency. By identifying inherent data groupings, subsequent supervised learning can be performed independently on each cluster, provided labeling information is available.

The second core category discussed is dimensionality reduction. This technique addresses large datasets composed of high-dimensional samples, such as high-resolution images. The chief goal of dimensionality reduction is to reduce the number of dimensions into a lower-dimensional embedding. Crucially, this reduction must occur without losing any useful information from the original dataset. The process aims to preserve the useful information pertinent to the task while actively discarding noise and redundancy.

Principal Component Analysis (PCA) is cited as a specific technique for achieving dimensionality reduction. This method effectively reduces statistical redundancy within the data and mitigates the negative effects associated with the cost of dimensionality. ### 03_6.103_K-Means_Video_7_min

# 6.103 K-Means
Video • 7 min - Summary

URL: https://www.coursera.org/learn/uol-cm3015-machine-learning-and-neural-networks/lecture/UL0mI/6-103-k-means

K-means clustering is a highly effective unsupervised learning algorithm designed to automatically discover patterns and groupings within data, such as separating average and wealthy income groups. The process begins by deciding the number of clusters, denoted as $K$, which defines how many distinct groups the data should be divided into. In the first step, the algorithm selects $K$ random points from the data, which are designated as the initial centroids. Once the centroids are established, the algorithm calculates the distance from every data point to each of these centroids. Data points are then assigned to the cluster corresponding to the nearest centroid, forming initial cluster boundaries. This initial grouping is the starting point for the iterative refinement process. The next critical step is recalculating the centroids; one effective method is to determine the mean of all data points contained within each cluster, establishing new centroid locations. It is important to note that a new centroid does not necessarily need to fall on an actual data point, but can be the precise mean of the cluster data. Using these newly calculated centroids, the algorithm again computes the distance from all data points to each centroid. Points are reassigned to the cluster of their closest centroid, causing the cluster boundaries to shift slightly. This entire sequence—calculating the cluster mean, determining distances, and reassigning points—is then repeated iteratively. The process continues until convergence, which occurs when the centroids cease to move or the cluster shapes no longer change. A significant limitation of K-means is that its final outcome is subject to local minima, meaning the result is heavily dependent on the initial centroid placement. To mitigate this sensitivity, the practical solution is often to restart the algorithm multiple times using various different initial centroids. This methodology applies whether $K$ is two, three, or any higher value representing the desired number of clusters. When dealing with multi-dimensional data, such as adding age to income, the basic procedure remains the same. However, a critical issue arises when features are on wildly different scales, like income measured in hundreds of thousands and age measured in tens. Before running K-means on multi-dimensional data, it is essential to scale the data to ensure all features contribute equally to the distance calculation. This scaling prevents features with large numerical ranges, like income, from dominating the clustering results over smaller-scaled features, such as weight. A common technique is min-max scaling, which restricts all data points to fall within the range of zero and one. The specific formula for min-max scaling is: $X_{scaled} = (X - X_{min}) / (X_{max} - X_{min})$. Utilizing this rescaling ensures that features like weight have a meaningful effect on the final clustering assignment.
